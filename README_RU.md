# SoundCloud → Telegram Monitor

Небольшой бот без меню и кнопок. Он периодически проверяет публичные поля профиля SoundCloud и присылает Telegram-сообщение, если API сообщает об изменениях.

## Что отслеживается
Только поля, которые SoundCloud API реально вернул для профиля: имя, описание, город/страна, число подписчиков/подписок, число треков/плейлистов, публичные лайки и аватар. Набор полей зависит от доступа и версии API.

**Ограничения:** это не push-уведомления и не полный журнал активности. Бот не гарантирует обнаружение каждого лайка/анлайка, кто именно подписался/отписался, и других событий, которых нет в доступном API. SoundCloud может ограничить или отклонить приложение. Используйте API в соответствии с условиями SoundCloud.

## Настройка
1. В @BotFather отзовите токен, который случайно отправили в чат, и получите новый. Не публикуйте токен.
2. Создайте `.env` на основе `.env.example`.
3. Заполните `TELEGRAM_BOT_TOKEN`. `TELEGRAM_CHAT_ID` уже указан как `8835091053`; проверьте, что этот чат первым написал боту команду `/start`.
4. В SoundCloud Developer portal создайте приложение с правдивым описанием. Если SoundCloud выдал `client_id` и `client_secret`, добавьте их в `.env`. Не отправляйте секреты в чаты и не коммитьте `.env` в GitHub.
5. Проверьте профильный URL. По умолчанию указан `https://soundcloud.com/skellx`.
6. Установите Python 3.10+ и выполните:

```bash
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

При первом успешном запросе бот сохранит исходное состояние в `state.json` и отправит сообщение о запуске. Далее проверка идёт каждые 15 минут.

## Постоянная работа
Для 24/7 нужен постоянно работающий сервер/VPS или хостинг с background worker. Запуск на телефоне или закрытом ноутбуке не обеспечивает 24/7. Dockerfile включён.

## Безопасность
- Никогда не добавляйте `.env` в GitHub.
- Не присылайте токены, пароли, коды 2FA или `client_secret` в чат.
- Если токен уже публиковался, немедленно отзовите его через @BotFather.
